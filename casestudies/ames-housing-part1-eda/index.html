Ames Housing - Part 1 - Exploratory Data Analysis

Dec 25, 2016 case studies

In this case study, we use the Ames Housing dataset to predict the sale prices of houses. In this first post, we clean the data and explore it. In the next post, we build models that predict the prices. A model is a formula that a computer learns from examples.

Data Summaries

The Ames Housing dataset has the sale prices of properties in Ames, Iowa, and 80 other attributes of each property. We call each attribute a feature. Each property has an Id number. The data comes in two parts: a training set and a testing set. Here are the number of rows (properties) and columns (features) in each set:

Label Encoding

The data description shows that the categories of many features have a natural order. These features are called ordinal features:

  • LotShape: Reg, IR1, IR2, IR3
  • LandSlope: Gtl, Mod, Sev
  • ExterQual: Ex, Gd, TA, Fa, Po
  • ExterCond: Ex, Gd, TA, Fa, Po
  • BsmtQual: Ex, Gd, TA, Fa, Po, None
  • BsmtCond: Ex, Gd, TA, Fa, Po, None
  • BsmtExposure: Gd, Av, Mn, No, None
  • BsmtFinType1: GLQ, ALQ, BLQ, Rec, LwQ, Unf, None
  • BsmtFinType2: GLQ, ALQ, BLQ, Rec, LwQ, Unf, None
  • HeatingQC: Ex, Gd, TA, Fa, Po
  • CentralAir: Y, N
  • KitchenQual: Ex, Gd, TA, Fa, Po
  • Functional: Typ, Min1, Min2, Mod, Maj1, Maj2, Sev, Sal
  • FireplaceQu: Ex, Gd, TA, Fa, Po, None
  • GarageFinish: Fin, RFn, Unf, None
  • GarageQual: Ex, Gd, TA, Fa, Po, None
  • GarageCond: Ex, Gd, TA, Fa, Po, None
  • Street: Grvl, Pave

Let’s check these choices. For every pair of features, we measure their association, which tells how strongly the two features are related. We use a measure that suits each type of pair: the Pearson correlation for two numerical features, Cramer’s V for two categorical features, and the correlation ratio for one numerical and one categorical feature. All these measures are near 0 when there is no relationship. Features with many categories can seem related to everything by chance, so Cramer’s V and the correlation ratio include a correction (bias correction) for this.

mAssoc <- association_matrix(dfClean %>% select(-Id))

  drop_na(association) %>%
  arrange(desc(abs(association)))

assoc_of <- function(f1, f2) {
  dfAssocPairs %>%
    filter((feature1 == f1 & feature2 == f2) | (feature1 == f2 & feature2 == f1)) %>%
    pull(association) %>%
    round(2)
}

Transforming Skewed Features

Many numerical features are right skewed. Can we change them with a simple formula (a transform), so that their relationship with log(SalePrice) becomes closer to a straight line? Let’s compare common transforms of three features: TotalSF, the strongest area feature; LotArea, which is very skewed; and GarageArea, which is almost not skewed. Each panel shows the R-squared of a straight line through the points. R-squared is a number from 0 to 1. It tells how much of the variation in log(SalePrice) the line explains:

What’s notable?

  • A log transform almost doubles the R-squared of LotArea (skewness 12.8), from 0.066 to 0.138. Without the transform, a few very large lots control the line. The log makes these large values smaller.
  • All the transforms improve TotalSF (skewness 1.5) a little. With a log, the R-squared goes from 0.61 to 0.647.
  • GarageArea (skewness 0.2) is almost not skewed, and the transforms make the fit worse. With a log, the R-squared goes down from 0.426 to 0.389. Also, the log cannot use the properties without a garage, because the log of 0 does not exist.
  • So, before we build linear models, we should transform only the very skewed features, not all of them.

Correlations with SalePrice

We keep the features whose correlation with SalePrice is at least 0.1 or at most -0.1. The Pearson correlation measures how close a relationship is to a straight line, so outliers and skewed features affect it strongly. The Spearman correlation uses the ranks of the values (1st, 2nd, 3rd, …) instead of the values. So it measures whether one feature always goes up (or always goes down) when the other goes up, even along a curve. If we compare the two, we can see which relationships are strong but not straight lines:
