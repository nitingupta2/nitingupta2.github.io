Diamonds - Part 3 - A polished gem - Building Non-linear Models

Dec 22, 2016 case studies

Other posts in this series:

  • Diamonds - Part 1 - In the rough - An Exploratory Data Analysis
  • Diamonds - Part 2 - A cut above - Building Linear Models

In the previous posts, we found out which attributes of a diamond are important for its price. An exploratory data analysis showed that carat, clarity and color are the most important features to predict price. Then we built linear models to predict the prices, and we chose the best model by its metrics.

In this post, we use non-linear models to predict the prices of diamonds, and we compare them with the linear models. A non-linear model can learn curved relationships and interactions between features by itself.

Training Non-linear Models

We use three types of non-linear models:

  • randomForest builds many decision trees and takes the average of their predictions. A decision tree predicts a value by asking a series of yes/no questions about the features, such as “Is carat more than 1?”.
  • xgboost (gradient boosting) builds many small decision trees one after the other. Each new tree corrects some of the errors of the trees before it.
  • keras builds a neural network. A neural network passes the features through layers of simple calculations, and it learns the strength of each connection from the data.

We follow some of the same steps as for the linear models, and we change some features:

  • Split the dataset into a training set with 75% of the diamonds and a testing set with 25%.
  • Keep the same mix of clarity grades in both sets (stratified sampling).
  • clarity, color and cut have ordered categories, from the lowest grade to the highest grade. randomForest can use these categories directly. But xgboost and keras need all the features as numbers. There are two methods to change categories into numbers:
    1. One-hot encoding: each category of clarity, color and cut becomes a new feature with the values 0 and 1. A disadvantage of this method is that the order of the grades is lost. But the training set is large, so the non-linear models can learn the order by themselves.
    2. Integer scores: the grades become the numbers 1, 2, 3 and so on, from the lowest grade to the highest. But this method assumes that the steps between all the grades are equal, which may not be correct here.
  • Center and scale all the values in the training set, so that all the features have similar ranges. Then put the features in a matrix (a table of numbers).
  • Train a non-linear model on the training set.
  • Make predictions on the testing set and calculate the metrics.
  • Put all the steps above in a function that takes the model formula and a random seed. The seed controls the random split into the training set and the testing set.
  • Run each model several times with different seeds, and calculate its average metrics. These averages show how well the model works on new data.

The R-squared values show that all the models learn the complex relationship between price and carat very well. For the linear models, we had to change both price and carat to a log scale. The neural network and the decision tree models learn this relationship by themselves. The root mean squared error (RMSE) is in dollars, so it is easy to understand. The average price of a diamond is about $4000, and the prices vary by about $4000 (the standard deviation). So the RMSE values of the models are very low. With carat, clarity and color, the RMSE is between $572 and $645. The best linear model with the same features has an RMSE of about $816.

The exploratory data analysis helps here, because the models with only carat, clarity and color give excellent results. If we add cut, the RMSE goes down only a little.

Even the base models with all the features (price ~ .) explain the variation in the prices very well, although some of their features repeat the same information. Decision trees and neural networks are not affected by such repeated information (multicollinearity) as much as linear models are. To find the most important features of these models, we can explain their predictions one at a time.

Local Interpretable Model-agnostic Explanations

LIME is a method to explain the predictions of a “black box” model, which is a model whose calculations are too complex for a person to follow. LIME explains one prediction at a time. It assumes that, close to a single diamond, the complex model behaves like a simple linear model. So LIME fits a simple model around that one diamond. The simple model then explains how the complex model makes its prediction for that diamond.

LIME uses these steps:

  • Take one diamond, and make many copies of it with small random changes to its features.
  • Measure how similar each copy is to the original diamond.
  • Use the complex model to predict the price of each copy.
  • Choose a small number (m) of features that best explain the predicted prices.
  • Fit a simple model to the copies, with the m features. Give more weight to the copies that are more similar to the original diamond.
  • Use the weights of the simple model to explain the prediction for the original diamond.

We know that x and y have a very strong correlation with carat, so they repeat the same information. That is why it is good practice to remove such repeated features before we train a model. For keras, the model with carat, clarity and color has the best metrics. For the decision tree models, the model with all the features is a little more accurate, but it needs many more features.

The scatter plots use both normal (linear) axes and log axes. The R-squared and RMSE values of the 3 methods are similar. But for expensive diamonds, the predictions of keras are more spread out than the predictions of the two decision tree methods. For cheap diamonds, the decision tree methods seem to predict the prices better, with less spread.

As with the linear models, the spread of the predicted prices increases with price. The decision tree methods keep their predictions close to the range of prices in the data. Their highest predictions are $18,340 (randomForest) and $19,118 (xgboost). The most expensive diamond in the testing set costs $18,823. A randomForest prediction is an average of prices from the training data, so it cannot be higher than those prices. xgboost adds up many small corrections, so its predictions can be only a little higher. A neural network, like a linear model, can predict prices far above the prices in the data (extrapolation). The highest price that keras predicts is $26,591. So the non-linear methods learn the relationships between price and the other features very well, and the decision tree methods also keep their predictions within a reasonable range.

Summary

  • All 3 non-linear methods learn the complex relationship between price, carat and the other features by themselves. They do not need feature engineering.
  • The exploratory data analysis helps us remove repeated features before we train the models. This makes the training faster. For keras, it also gives much better metrics.
  • keras neural networks train the fastest, because they can use a GPU (a graphics processor that does many calculations at the same time).
  • Of the two decision tree methods, xgboost trains much faster than randomForest.
  • randomForest and xgboost can use several CPU cores at the same time. On a local computer, the amount of memory (RAM) is the only limit.
